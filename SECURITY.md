# Security scope

This repository is a local learning demonstration with synthetic data. Do not use it to store confidential documents or expose it publicly. The two vulnerability scenarios in the study are hypothetical; the served routes contain the defensive controls.

Supported review target: the current default branch. There is no production support commitment.

For a suspected vulnerability, use GitHub private vulnerability reporting if available. Otherwise open an issue containing only a general description and ask for a private reporting channel. Do not include passwords, tokens, databases or confidential content. Reproduce issues using fictional records.

The application lacks production controls including login throttling, MFA, TLS deployment, log retention, immutable audit storage and operational monitoring. Checks cover defined cases and known advisories; they do not establish that all vulnerabilities have been found.
